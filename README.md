# taskr

A tiny command-line to-do list, built to practice professional Git workflows
(from freeCodeCamp's "Git for Professionals" course).

    python taskr.py add "Write report"
    python taskr.py list

## Commands

| Command            | What it does                 |
|--------------------|------------------------------|
| `add <title>`      | Add a new task               |
| `list`             | Show all tasks               |
| `done <number>`    | Mark a task as complete      |
| `delete <number>`  | Remove a task                |
